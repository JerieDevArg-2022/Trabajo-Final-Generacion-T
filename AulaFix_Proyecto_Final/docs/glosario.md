# Glosario

- **Incidencia:** reporte identificado sobre una falla de infraestructura tecnológica.
- **Solicitante:** alumno que registra una incidencia.
- **Técnico:** usuario autorizado para atender los casos asignados.
- **Administrador:** coordinación que asigna responsables y controla el cierre.
- **Prioridad:** nivel de urgencia elegido entre baja, media, alta y crítica.
- **SLA (plazo objetivo):** fecha de atención objetivo calculada desde el alta según la prioridad. Es un indicador, no una garantía.
- **Abierto:** reporte aún no atendido.
- **En proceso:** técnico trabajando en el reporte.
- **En espera:** reporte pausado hasta contar con condiciones para continuar.
- **Resuelto:** problema reparado con descripción de la solución.
- **Cerrado:** reporte dado por finalizado por coordinación.
- **Cancelado:** reporte anulado antes del cierre.
- **Repuesto:** unidad física consumible usada durante una reparación.
- **Stock mínimo:** umbral a partir del cual aparece una alerta de inventario.
- **Auditoría:** historial ordenado de acciones con usuario, fecha y detalle.
- **Transacción:** conjunto de cambios de base de datos que se confirman o revierten juntos.
